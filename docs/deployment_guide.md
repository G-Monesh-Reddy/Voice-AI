# Home Credit LAP Voice Agent - Deployment Guide

This guide provides step-by-step instructions for configuring, deploying, and demonstrating the **Home Credit Loan Against Property (LAP) Voice Agent** on enterprise voice platforms (**Retell AI** and **Bolna**).

---

## 1. Prerequisites & Environment Setup

1. **Python Environment**: Ensure Python 3.11+ is installed.
2. **Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Environment Configuration**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Add your credentials:
   - `GEMINI_API_KEY`: Obtained from [Google AI Studio](https://aistudio.google.com).
   - `GEMINI_MODEL`: Default is `gemini-2.5-flash`.
   - `RETELL_API_KEY` & `RETELL_AGENT_ID`: Obtained from [Retell AI Dashboard](https://beta.retellai.com).
   - `BOLNA_API_KEY` & `BOLNA_AGENT_ID`: Obtained from [Bolna Dashboard](https://www.bolna.dev).

---

## 2. Deploying on Retell AI (Recommended)

Retell AI provides low-latency voice agents with native Indian English and Hindi voice synthesis.

### Step 2.1: Create an Agent in Retell AI
1. Log in to the [Retell AI Dashboard](https://beta.retellai.com/).
2. Navigate to **Agents** → Click **Create New Agent**.
3. Select **Response Engine**:
   - Choose **Retell LLM** for hosted Gemini integration, or **Custom LLM (WebSocket)** if hosting this repository's webhook server.

### Step 2.2: Configure System Prompt & Dynamic Variables
1. Paste the full content of [`prompts/system_prompt.txt`](file:///c:/Users/mones/Desktop/Voice%20AI/prompts/system_prompt.txt) into the **System Prompt** field.
2. In the **Dynamic Variables** section, map the following keys:
   - `customer_name`: Target customer name (e.g., `Rahul Sharma`).
   - `company_name`: `Home Credit`.
   - `agent_name`: `Pooja`.
   - `agent_gender`: `female`.
   - `language_to_speak`: `English` or `Hindi`.
   - `current_date`, `current_day`, `current_time`: Injected by platform.
   - `additional_context_from_rag`: Product reference details.

### Step 2.3: Recommended Voice Selection
- **Indian English**:
  - `ElevenLabs - Pooja` or `Azure - en-IN-NeerjaNeural`
- **Hindi**:
  - `ElevenLabs - Priya` or `Azure - hi-IN-SwaraNeural`
- Set Speech Rate: `1.0x` | Temperature: `0.2`

### Step 2.4: Call Ending & Webhook Configuration
- Under **End Call Settings**: Enable *"End call when LLM triggers hangup"*.
- Set **Webhook URL** to: `https://<your-public-url>/webhook/retell`.
- Use a tool like **ngrok** for local testing:
  ```bash
  ngrok http 8000
  ```

## 3. Initiating Live Calls and Testing

### Option A: Outbound Call via CLI / Python Script
```python
from app.voice_platform import RetellAIAdapter

adapter = RetellAIAdapter()
call_response = adapter.initiate_call(
    to_number="+919876543210",
    customer_name="Rahul Sharma",
    dynamic_vars={"language_to_speak": "English"}
)
print(call_response)
```

### Option B: Web Test Call via Retell AI Dashboard
1. Go to your agent page in Retell AI Dashboard.
2. Click **Test Audio** / **Web Call**.
3. Speak with the agent directly in your browser using your microphone.

## 4. Retrieving Audio Recordings & Call Transcripts

### From Retell AI API
```python
from app.voice_platform import RetellAIAdapter

adapter = RetellAIAdapter()
call_id = "call_abc123xyz"

# Fetch full transcript
transcript_data = adapter.get_transcript(call_id)
print("Transcript:", transcript_data["transcript"])

# Fetch audio recording URL
recording_url = adapter.get_recording_url(call_id)
print("Recording URL:", recording_url)
```

### From Retell AI Dashboard (Shareable Reviewer Links)
1. In the dashboard, click **Call History**.
2. Locate the completed call.
3. Click the **Share** button on the top right of the call view.
4. Copy the public shareable link (e.g., `https://dashboard.retellai.com/call/call_...`).
5. Anyone with this link can listen to the full audio recording and read the synced transcript.

---

## 5. Deploying on Bolna (Alternative)

1. Log in to [Bolna.dev](https://www.bolna.dev/).
2. Create an Agent with LLM set to **Gemini**.
3. Configure Voice to **Polly - Aditi** or **Deepa**.
4. Set Webhook URL to `https://<your-public-url>/webhook/bolna`.
5. Trigger outbound calls using `BolnaAdapter.initiate_call()`.

---

## 6. Local Simulation Mode (No Live Telephony Required)

If live platform credits or phone numbers are not currently configured, use the built-in interactive simulator:

```bash
# Run interactive conversation in terminal
python -m app.main --interactive --name "Rahul Sharma" --language "English"

# Run automated batch test scenarios
python -m app.main --scenario scenarios/test_scenarios.json

# Start the webhook and REST API server
python -m app.main --server
```

> [!NOTE]
> All transcripts generated by local simulation are labeled as **SIMULATED** in `examples/`. Never represent local simulation logs as live telephone recordings.
